# Mój Oddech

Aplikacja PWA wspierająca osobę z amyloidozą płuc: leki, respirator (cel 8 h/dzień), pomiary (SpO2, waga, ciśnienie), 28-dniowy jadłospis niskosolny, dziennik samopoczucia i raport dla lekarza.

Dane pozostają na telefonie (localStorage); opcjonalna codzienna kopia do prywatnego repo GitHub.

Instalacja i obsługa: [INSTRUKCJA.md](INSTRUKCJA.md)

Aplikacja nie zastępuje porady lekarskiej.
